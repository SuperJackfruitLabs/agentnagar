# Leisure and community

[Catalogue](README.md) · [Shared characteristics](CHARACTERISTICS.md) · Proposed asset kinds, 2026-09-18.

These assets make the city a place to spend time. Sessions and events can use the same seating, storage, display and permission capabilities as workshops.

All rows inherit the shared identity, ownership, presentation, accessibility and lifecycle characteristics where applicable. The fields below distinguish this kind. Interactions describe intended behavior, not implemented capabilities.

| ID | Kind and description | Treatment | Distinguishing characteristics | Interactions and states |
| --- | --- | --- | --- | --- |
| SOC-01 | **Game table and board.** Shared tabletop game surface. | Movable | Seat anchors, game type, turn/session state, reset and spectator positions. | Join/play/leave; visible board does not permit resetting another session. |
| SOC-02 | **Game piece, card and die.** Small object participating in a game or puzzle. | Portable | Set membership, role, allowed moves, visibility and return location. | Move through game rules; distinguish session pieces from freely owned collectibles. |
| SOC-03 | **Instrument.** Playable music object used alone or in an event. | Portable | Grip/seat, sound set, volume, animation and compatible performance actions. | Play/store/perform with space permissions; audio has captions or visual cues where useful. |
| SOC-04 | **Stage and performance platform.** Focus for assemblies, demonstrations and performances. | Fixed | Stage bounds, presenter anchors, audience sightlines, access and equipment mounts. | Book/host/attend; speaking and broadcast permissions independent. |
| SOC-05 | **Sports and playground equipment.** Authored play structures or activity stations. | Fixed | Activity type, participant slots, clearance, rules and reset behavior. | Join/use/leave; usable action and suitable avatars defined per variant. |
| SOC-06 | **Ball and recreational prop.** Portable object used in a bounded play activity. | Portable | Size, material, game association and optional physics behavior. | Carry/place/store initially; throwing and collision gameplay require later rules. |
| SOC-07 | **Exhibition plinth and display case.** Surface or enclosure presenting an artifact. | Movable | Mount slots, visibility, case access, lighting and artifact reference. | Display/inspect; placing an object on view does not make it available to take. |
| SOC-08 | **Festival canopy and decoration kit.** Temporary structures and decorations for community events. | Movable | Footprint, mounts, duration, wind appearance, clearance and return storage. | Place/decorate/remove under event rights; expiry must resolve attached belongings. |
