# First Guild scene — pinned concept-art references

Reference snapshot · 2026-09-22 · [Numbered asset sheet and tracker](FIRST_GUILD_SCENE.md)

These are the thirty existing style manifests’ selected revisions as inspected on this date. Selection does not imply review approval. Use the linked **image and review** together, and read the style brief. No new visual direction is introduced here. The humanoid experiment is excluded.

For each GS asset, record its chosen style, exact sheet revision and relevant panel on the individual sheet before authoring. Reference artwork informs design; it is not a finished asset. If a manifest later changes, this pinned index stays historical until deliberately updated. A reference change requires an impact review; it must not silently mark an existing asset tested or accepted.

| Reference sheet | Apply to |
| --- | --- |
| City perspectives | Ground, paths, tree, buildings, roof/facade masses, map layout, daylight and overall scene |
| Living community | Workshop/home interiors, furniture, terminals, dressed characters, body proportions and compatible rig design |
| Creating/exploring | Props, construction/material details, environmental treatment and movement context |
| Interfaces/perspectives | Signage, public cards, facility/map/mobile presentation and character portrait continuity |

Where the source does not depict a specific prop or Guild member, derive its design from the chosen style’s grammar and mark that design as new and pending review. Do not pretend a concept panel already defines fourteen distinct Guild characters. Consult the [comparison contract](../../vision/style-studies/shared/CONSISTENCY-CONTRACT.md) and [sheet program](../../vision/style-studies/shared/sheet-program.md).
