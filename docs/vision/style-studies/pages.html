Thirty ways to draw one city

Each page describes the project and one candidate style, and is built in that style: some are games, some publications, some interfaces. Every page shows the same reference district and the same seven core notes. The sheets are AI-generated concept illustrations (released under CC0 1.0; each page names the generator where it was recorded), not game captures, and selection does not imply review approval. Since RD18 (2026-09-24) the city is built to work in any style: low-poly (11) and pixel art (08) prove it, and Voxel (02, selected for the first-scene experiment) is the third style pack.
