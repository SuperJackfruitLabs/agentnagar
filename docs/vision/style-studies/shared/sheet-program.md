# Shared sheet program

Every style has four sheets, each a 1536 × 1024 PNG with four panels. These are
concept illustrations, not implemented interfaces or production geometry.
The [comparison contract](CONSISTENCY-CONTRACT.md) governs the shared district,
agent identity, camera intent and interaction semantics.

| Sheet ID | Top left | Top right | Bottom left | Bottom right |
| --- | --- | --- | --- | --- |
| 00-city-perspectives | Map | Top-down | Diagonal | Street |
| 01-living-community | Workshop interior | Home interior | Conversation | Public gathering |
| 02-creating-exploring | Build mode | Transit | Night and rain | Waterfront park |
| 03-interfaces-perspectives | Facility | Mobile | Rooftop | AR tabletop |

Transit boarding and passenger-interior variations are identified in historical
reviews. A shared label does not certify exact geometry or complete compliance.
Use the [reference district](reference-district.svg) for comparison intent and
per-revision reviews for observed limitations.
