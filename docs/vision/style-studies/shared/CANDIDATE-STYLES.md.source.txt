# Twenty candidate city styles

Proposed on 2026-09-18 for the next round of visual exploration, and
illustrated on 2026-09-19. Each candidate now has its own folder in the parent
directory with the same sheet program as styles 01 to 10, and a README that
describes what the generated sheets show. This document remains the brief:
no production assets, engine choice, or style selection is implied. The
original generation prompts for these twenty styles were not saved, so the
table and frame contract below record the initial intent. New correction
prompts are saved beside their outputs; the [consistency contract](CONSISTENCY-CONTRACT.md)
and [progress record](REPAIR-STATUS.md) govern that subsequent pass.

The set deliberately varies rendering language, material language,
architecture, light, and cultural reference. The image studies use the same
riverfront maker-city program and the four established camera views so each
result can be compared with the existing collection, and each style has been
tested on the workshop, home, conversation, gathering, build mode, transit,
rain, waterfront, mobile, rooftop, and tabletop experiences. The four missing
city-perspectives sheets (15, 23, 24, 25) were added in the correction pass.

## Suggested evaluation order

All twenty are illustrated, so this is an order for review rather than for
generation. Start with **11 Low-poly tropical diorama**, **12 Gouache storybook**, **18 Art
Deco civic futurism**, and **23 Cassette futurism**. Together they test the
project's existing tropical low-poly direction, two illustration/material
approaches, and two different visions of civic technology. They are distinct
from the current ten and can be evaluated without using a living cultural
tradition as visual decoration.

Then review the remaining candidates in groups chosen by what the first set
reveals: print and surface language (13–16, 27–29), architecture and geometry
(17–22), or material and world premise (24–26, 30). For every candidate,
assess landmark recognition, resident expression, route visibility, text and
non-color interaction cues, animation stability, and cost on the lowest
target device. A style that works in one static city view is not yet a viable
city-wide presentation system.

## Frame contract

The four sheets for one style share one frame treatment. The frame is a
presentation system around the generated panels, not a claim that the city
uses one universal material. Every output remains 1536×1024 landscape, with
the same 20 px outer frame, the same narrow panel gutters, and the same footer
position within a style. The outer frame may express the style through a
restrained material or color, while labels stay high-contrast and readable.
