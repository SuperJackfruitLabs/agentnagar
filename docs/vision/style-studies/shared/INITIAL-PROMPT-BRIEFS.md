# City style studies — 2026-09-18

Generated with the built-in image-generation tool for design discussion. These are concept illustrations, not game captures or performance benchmarks. Map, top-down, diagonal and street panels explore the same general urban program; camera geometry and geographic consistency are approximate.

## Prompt briefs

All four generation prompts requested a landscape 2×2 sheet showing MAP, TOP-DOWN, DIAGONAL, and STREET views of a riverfront maker metropolis with a central tree square, workshop, library, tram boulevard, and dense downtown. Map panels requested flat cartography; top-down panels requested vertical roof views; diagonal panels requested angled city overviews; street panels requested pedestrian eye level.

- **01-graphic-city.png:** Graphic minimalist 3D; coral/navy/cream/mint palette, clean geometry, flat shading, geometric trees, modern workshops and roof gardens.
- **02-voxel-city.png:** Chunky cube-built architecture, stepped terrain, blocky characters, bright green/blue/orange palette, modern workshops and an orange-and-cobalt library.
- **03-ink-city.png:** Hand-drawn ink and watercolor; ivory paper, crosshatching, ochre/rust/sage/teal washes, industrial brick workshops and a repurposed warehouse library.
- **04-realistic-city.png:** Architectural realism; natural daylight, plausible materials and human proportions, brick workshop and glass-and-stone library.

The exact original prompts have now been recovered from the generation calls and saved as `00-city-perspectives.prompt.md` in each style folder. No style has been selected. The original filenames below are historical; each image is now preserved as `00-city-perspectives.png` in its corresponding style folder and included in the repository checkpoint.

## Additional six styles

Generated using the built-in image tool, each with the same requested four-view layout and city landmarks. These are visual explorations; exact camera geometry and landmark positions vary between panels.

- **05-claymation-city.png:** Tactile stop-motion clay; rounded architecture, sculpted residents, warm turquoise/mustard/cream/brick-red palette.
- **06-anime-city.png:** Crisp cel-shaded anime; limited shadow steps, selective outlines, vivid daylight, contemporary Japanese-influenced urban forms.
- **07-paper-craft-city.png:** Folded cardstock and cut-paper city; visible edges, folds and fibers, origami foliage, lavender/pistachio/terracotta palette.
- **08-pixel-art-city.png:** Crisp raster pixel art; visible clusters, controlled dithering, limited palette, overhead sprites, isometric and eye-level pixel scenes.
- **09-solarpunk-city.png:** Optimistic retro-futurist solarpunk; curved ceramic structures, brass details, solar canopies, terraced planted towers.
- **10-neon-noir-city.png:** Neon noir; angular dense vertical architecture, deep navy/charcoal, cyan/amber/magenta light, rain-darkened streets and elevated transit.

Each style README links to its recovered original prompt. No benchmark, engine selection, or production asset approval is implied.
