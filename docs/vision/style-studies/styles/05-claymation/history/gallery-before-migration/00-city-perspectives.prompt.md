# City perspectives — original generation prompt

Exact prompt recovered from the original image-generation call in the design conversation on 2026-09-18. This is the prompt used for [00-city-perspectives.png](../../sheets/00-city-perspectives/r001/image.png), not a reconstruction. No reference image was supplied in this call.

## Prompt

```text
Create a high-resolution landscape 2x2 art direction sheet for a large explorable maker city. Four spacious panels clearly labeled MAP, TOP-DOWN, DIAGONAL, STREET. STYLE: TACTILE CLAYMATION / STOP-MOTION MINIATURE. Unmistakable hand-shaped colored clay, softened rounded building corners, subtle fingerprints and tool impressions, thick sculpted window frames, plump stylized human figures, rounded clay tree canopies, warm turquoise mustard cream and brick red. Professional stop-motion set charm; NO photorealistic people, no voxel blocks, no ink outlines. City landmarks consistent across views: river west, bridge north, central tree square, maker workshop west of square, public library east, tram boulevard south, many dense blocks and taller downtown towers beyond. Buildings contemporary, original architecture; a city with workshops and homes rather than fantasy castle village. MAP upper left is a truly flat 2D map drawn with clay-color footprint shapes and fine road lines, no tilted structures or extrusions. TOP-DOWN upper right is camera exactly vertically above the clay city rooftops and square; no horizon. DIAGONAL lower left is wide 45-degree elevated view across many blocks and clay skyscrapers, city-scale composition. STREET lower right is pedestrian eye level among friendly sculpted inhabitants with workshop and library entrances and skyline beyond. All four panels have SAME clay aesthetic and shared city program. Clear useful differences in viewpoint. Soft daylight, sharp details throughout, no shallow depth of field that obscures the city. Neutral narrow gutters and legible labels. Footer '05 · Claymation city — concept art'. No extra captions, no logos, no UI or benchmark claims.
```
