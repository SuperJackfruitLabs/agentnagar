Per-style generation records, original gallery snapshots and repair reports are
under each style's `history/`. Historical JSON retains old path identifiers; use
the ledger to resolve them. Original Markdown bytes are preserved beside readable
copies as `.md.source.txt` files.

The hash-locked `.md.source.txt` copies keep their original absolute links to
the pre-publication history, which are not reachable in this repository. The
readable `.md` views of the two review records re-point those links at the
byte-identical migrated files and the per-style folders.
