# Reference workflows

Small, inspectable examples that preserve working experiments. They record
what was demonstrated and how to repeat it; they do not establish production
readiness or change Agentnagar's planning gates.

  an agent-assisted modeling reference, procedural source, editable asset,
  animation preview and engine verification.
